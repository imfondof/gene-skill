# 双链提取协议

> 从原始信息到人格技能——表层链与深层链的同步编码

## 核心创新：双链结构

传统的人物框架提取是单链的——只记录此人说了什么、怎么想的。
Gene Skill 提取双链——**表层链**（他说了什么）和**深层链**（他为什么这样说）同步编码。

类比DNA的双螺旋：
- **表层链**（编码链）：直接引用、公开立场、明示观点——可观测的行为和言论
- **深层链**（模板链）：未说出的假设、防御性表达背后的恐惧、反复强调暗示的不安全感——驱动表层行为的隐藏结构

双链对齐时，表层和深层可能一致（此人言行合一），也可能不一致（这个不一致本身就是最有价值的信号）。

---

## 一、表层链提取

### 提取对象
- 此人的直接引用（一手来源）
- 公开声明的立场和观点
- 反复出现的论点和术语
- 可观测的决策和行为

### 提取规则
1. **原文优先**：尽量使用原始引用，不要用自己的话转述
2. **频率标记**：同一观点出现≥3次标记为「高频」，出现≥5次标记为「核心」
3. **来源标注**：每条信息标注一手/二手/推测
4. **矛盾保留**：表层链内部的矛盾直接记录，不调和

---

## 二、深层链提取

深层链是 Gene Skill 的核心差异点。它编码的是表层行为背后的隐藏结构。

### 五种深层信号

#### 信号1: 反复强调 → 不安全感映射
**规则**：一个人反复强调的东西，往往是他最不确定的。

| 表层链 | 深层链推断 |
|--------|----------|
| 反复说「我不在乎别人怎么看」 | 可能极度在意外界评价 |
| 反复强调「我做的决定都是理性的」 | 可能对自己的情绪化决策感到不安 |
| 反复提「从第一天起我就知道」 | 可能事后合理化了很多不确定性 |

**操作**：统计此人在不同场景中反复强调的主题，推断对应的深层不安全感。标注为推断，给出证据链。

#### 信号2: 防御性回避 → 恐惧映射
**规则**：一个人系统性回避的话题，指向他的核心恐惧。

识别方法：
- 被问到某类问题时转移话题
- 用幽默/攻击/抽象化来回避具体回答
- 对某些批评反应过度（攻击力度与批评强度不成比例）

**操作**：从Agent 2（对话）和Agent 4（他者）的数据中，识别系统性回避模式，推断对应的恐惧。

#### 信号3: 理想化他人 → 自我匮乏映射
**规则**：一个人反复赞美他人的某个特质，可能指向他自己在这个维度上的匮乏感。

| 表层链 | 深层链推断 |
|--------|----------|
| 反复赞美某人的「专注力」 | 可能觉得自己注意力分散 |
| 反复赞美某人的「勇气」 | 可能在某些情况下觉得自己不够勇敢 |

**操作**：从推荐书单、公开赞美、智识谱系中，提取此人反复理想化的特质，推断自我匮乏维度。

#### 信号4: 立场突变 → 认知跃迁映射
**规则**：一个人突然改变长期立场，背后通常有一个未公开的关键体验。

识别方法：
- 对比不同时期的公开表态
- 寻找从A到B的转变点
- 推断可能的催化事件

**操作**：从Agent 6（时间线）中识别立场突变，推断催化事件和深层认知变化。这些直接输入维度5·时间。

#### 信号5: 言行不一致 → 内在冲突映射
**规则**：言语和行为的不一致，指向价值观层面的内在冲突。

| 表层链（言） | 表层链（行） | 深层链推断 |
|------------|------------|----------|
| 「我重视工作生活平衡」 | 一周工作100小时 | 核心驱动力（可能是恐惧/野心）压过了声称的价值观 |
| 「我信任我的团队」 | 微观管理每个细节 | 控制需求与信任理想之间的张力 |

**操作**：从Agent 5（决策）和Agent 3（表达）的数据中交叉对比言行，识别核心内在冲突。

## 三、双链对齐

### 对齐状态分类

| 对齐状态 | 含义 | 处理方式 |
|---------|------|---------|
| **一致** | 表层和深层指向同一方向 | 高置信度，直接编码为核心技能 |
| **互补** | 深层链补充了表层链的上下文 | 两者同时记录，标注互补关系 |
| **矛盾** | 表层和深层指向不同方向 | 最有价值的信号——同时保留，编入维度6·阴影 |
| **无深层** | 只有表层信息，无法推断深层 | 标注「深层链缺失」，降低置信度 |

### 对齐操作步骤

1. **逐条对齐**：对每条重要的表层信息，尝试推断对应的深层链
2. **交叉验证**：用来自不同Agent的数据相互验证深层推断
3. **矛盾标记**：表层-深层矛盾用 `⚡` 标记，这些矛盾优先输入Chr-6
4. **置信度评估**：深层推断标注置信度（有证据链 vs 纯推测）

## 四、信念强度评估

每个心智模型和决策启发式需要量化信念强度 ∈ [0, 1]。

### 评估维度

| 维度 | 测量方法 | 权重 |
|------|---------|------|
| **频率** | 在不同场景中出现次数 | 25% |
| **一致性** | 是否跨时间段保持稳定 | 25% |
| **行动匹配** | 是否用实际行动践行 | 30% |
| **代价承受** | 是否在有代价时仍坚持 | 20% |

### 信念强度刻度

| 范围 | 含义 | 典型证据 |
|------|------|---------|
| **0.9-1.0** | 核心信念，身份级 | 在所有场景中一致，为此付出巨大代价仍不动摇 |
| **0.7-0.8** | 强信念，有条件 | 跨多数场景一致，但在极端情况下可能妥协 |
| **0.5-0.6** | 观点，可能改变 | 在某些场景中表达，但未被严格检验 |
| **0.3-0.4** | 试探性想法 | 偶尔提到，可能在发展中 |
| **0.1-0.2** | 嘴上说说 | 表层表达但行动不匹配 |

### 计算方法

```
信念强度 = 频率分(0-1) × 0.25
          + 一致性分(0-1) × 0.25
          + 行动匹配分(0-1) × 0.30
          + 代价承受分(0-1) × 0.20
```

**关键规则**：如果「行动匹配分」< 0.3（说一套做一套），无论其他维度多高，总分不得超过 0.5。言行不一致是信念强度的硬性天花板。

## 五、心智模型识别的四重验证

一个论点要被认定为心智模型，必须通过四重验证。

### 验证1: 跨域复现
同一思维框架出现在至少2个不同领域。

### 验证2: 有生成力
用这个模型可以推断此人对新问题的可能立场。

### 验证3: 有排他性
不是所有聪明人都会这样想，体现此人独特视角。

### 验证4: 深层链一致
表层表达的模型与深层链推断的驱动力一致。

| 验证结果 | 处理 |
|---------|------|
| 四重全过 | 核心心智模型，信念强度 ≥ 0.7 |
| 过前三重但第四重不过（表里不一） | 标注为「声称的模型」，同时编码真实的深层驱动，两者差异记入Chr-6 |
| 过1-2重 | 降级为决策启发式 |
| 0重 | 丢弃 |

## 六、矛盾处理原则

矛盾是人格的核心特征，不是需要修复的Bug。以下是四种矛盾类型分类。

### 四种矛盾类型

1. **时间性矛盾**（观点演化）
   - 早期说A，后来说B → 记录演化轨迹，输入Chr-5

2. **领域性矛盾**（不同场景不同规则）
   - 工作中主张X，生活中主张Y → 分领域记录，输入情境调度层

3. **本质性张力**（价值观内在冲突）
   - 既追求自由又重视纪律 → 记录为核心张力，输入Chr-1

4. **表里矛盾**（新增：双链不一致）
   - 表层说A，深层驱动指向B → 最有价值的信号，输入Chr-6

### 错误的处理方式
- ❌ 选一边忽略另一边
- ❌ 编一个调和的解释
- ❌ 只保留表层链，丢弃深层推断
- ❌ 把推断当事实

## 七、各维度的提取来源映射

| 维度 | 主要数据来源（Agent） | 提取重点 |
|------|---------------------|---------|
| 维度1·认知 | Agent 1,2,5 | 心智模型（四重验证）+ 决策启发式 + 信念强度 |
| 维度2·情绪 | Agent 7,2,4 | 触发器（双链）+ 调节策略 + 基线情绪 |
| 维度3·关系 | Agent 8,4 | 角色映射 + 权力偏好 + 信任模式（双链） |
| 维度4·叙事 | Agent 3,2 | 核心神话（双链）+ 语言指纹 + 自我叙事 |
| 维度5·时间 | Agent 6,5 | 跃迁事件 + 进化向量 + 预测轨迹 |
| 维度6·阴影 | Agent 4 + 所有矛盾 | 盲区 + 防御 + 未表达潜能（全部来自深层链和矛盾） |
| 情境调度 | 综合全部 | 情境→激活矩阵 + 压力开关 |

## 八、质量自检清单

### 双链完整性
- [ ] 每个核心心智模型都有表层链+深层链？
- [ ] 深层推断都标注了置信度和证据链？
- [ ] 表层-深层矛盾被识别并记入Chr-6？

### 信念强度
- [ ] 每个模型/启发式都有量化的信念强度？
- [ ] 言行不一致的信念强度不超过0.5？
- [ ] 信念强度分布合理（不全是0.9，也不全是0.5）？

### 维度覆盖
- [ ] 六条维度都有实质内容（非占位符）？
- [ ] 信息不足的维度已标注「数据不足」？
- [ ] 情境调度层有≥3组情境映射？

### 推断边界
- [ ] 所有深层推断都标注为推断（非事实）？
- [ ] 维度6·阴影遵守伦理边界（参考ethics-boundary.md）？
- [ ] 虚构/设计的技能片段有明确标注？
